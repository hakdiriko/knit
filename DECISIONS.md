# Decisions

One line per decision, plus why. Newest at the bottom.

- 2026-10-10: Plug-in name **viber** (Hakan's working name); the repo stays `knit`. Why: Hakan named it.
- 2026-10-10: Plug-in codes `Hakd` (manufacturer) / `Vibr` (plug-in), bundle id `com.hakdiriko.viber`. Why: hosts identify plug-ins by these; they must never change, or saved Live sets lose the device.
- 2026-10-10: JUCE pinned to 8.0.15 via CMake FetchContent. Why: the brief asks for JUCE 8.x and 8.0.15 is its latest release; JUCE 9 (9.0.3) now exists and gets evaluated before the Phase 3 WebView UI work.
- 2026-10-10: Windows build links the MSVC runtime statically. Why: the VST3 then loads without a Visual C++ redistributable on Hakan's machine.
- 2026-10-10: macOS build is universal (arm64 + x86_64), minimum macOS 11. Why: one download for any Mac.
- 2026-10-10: CI runs on every push for Windows, macOS and Linux; pluginval at strictness 10 on every platform, `auval -strict` for the AU. Why: the playbook checklist asks for strictness 10, and Hakan never compiles.
- 2026-10-10: The discovery audit runs in CI on the Linux VST3 and fails the build on any FAIL. Why: "0 FAIL" is part of done, and pedalboard loads Linux VST3s headless.
- 2026-10-10: Audit test signal "percussive" normalized to a −6 dBFS peak (it peaked at +4.3 dBFS). Why: a clipping input made a pure passthrough fail BLOWUP, which measures the test signal, not the plug-in.
- 2026-10-10: Phase 0 INSERT_DULL warnings are expected. Why: the plug-in is a passthrough until Phase 1. (Gone as of Phase 1.)
- 2026-10-10: The parameter tree (APVTS) exists from day one, empty. Why: state save/recall is wired and tested by pluginval before the first knob lands.
- 2026-10-10: The `audio-plugin-dev` skill is not vendored into `.claude/skills/`. Why: it is available to Claude sessions in this project from Hakan's account; vendoring it only when it isn't (per Hakan).
- 2026-10-10: Phase 1 parameter IDs `ecology`, `size`, `tone`, `mix`, `output`, `bypass` (version 1). Why: hosts store automation and state by ID, so they never get renamed.
- 2026-10-10: Ecology drives coupling `c` and per-node loop gain `g` on separate paths; each node crosses g = 1 between 70% and 76%. Why: playbook rule of thumb, and staggered crossings make the tip into self-oscillation a blur instead of a step.
- 2026-10-10: Shift node runs an octave up and an octave down at once, and Tone balances them (dark = downward spirals, bright = shimmer). Why: gives Tone a second, musical job without a new knob; Character takes over intervals in Phase 2.
- 2026-10-10: Phase 1 Memory node uses its own 3.4 s buffer with 4 Hann grains, reach 0.2–2.6 s from Size. Why: the brief puts the 30 s memory buffer, Memory knob and tape slowdown in Phase 2; this keeps the node audible now.
- 2026-10-10: Resonator pitch follows Size continuously (520 Hz → 65 Hz) and glides. Why: tape-like bends feel alive; snapping to a scale is Phase 4.
- 2026-10-10: "Starvation": loop gain above 0.8 fades toward 0.8 when the input stays below about −65 dBFS (≈1.5 s envelope + 2 s ramp). Why: life-regime drones stay driven by the input and don't ring forever after the transport stops.
- 2026-10-10: Small fixed random-walk drift on delay times (0.25–0.4%, golden-ratio periods, fixed seeds). Why: breaks up metallic FDN ringing now; Phase 2 Motion scales it. Fixed seeds keep renders repeatable.
- 2026-10-10: Auto-gain measures per-channel power (not mono sum) with fast-rise/slow-fall envelopes (80 ms / 0.8 s) and holds while the input is silent. Why: a wide wet signal read as quiet and got over-boosted; a sudden loud wet now gets pulled back in ~100 ms; tails aren't pumped up.
- 2026-10-10: Safety limiter is instant-attack, linked, 120 ms release, −0.3 dBFS ceiling, no look-ahead. Why: guarantees no sample over the ceiling with zero latency, so the null test and Live's latency stay untouched.
- 2026-10-10: Bypass is a host-visible parameter with a 30 ms crossfade, and the network keeps running while bypassed. Why: click-free on/off, and un-bypassing returns to a living network.
- 2026-10-12: Sync (parameter `sync`, version hint 2, default off) snaps Echo, Shift and Memory to the note value nearest (by log distance) to Size's free time, choosing from straight, dotted and triplet values 1/64 to 1/1 that fit each node's buffer. Why: Size keeps its small-to-large feel at any tempo, and the playbook keeps the Resonator free so it stays pitched. Shift is synced too because its repeats are rhythmic.
- 2026-10-12: Synced Memory grains replay 1 to 4 quarters of the (synced) reach back. Why: random free offsets would land off the grid and undo the sync.
- 2026-10-12: Without a host tempo, Sync leaves the nodes free (no 120 BPM guess). Why: playbook §8; a wrong guess sounds worse than free time.
- 2026-10-12: The audit skips `sync`. Why: pedalboard has no play head, so Sync is a no-op there; the synced path was audited locally with a temporary forced tempo (70, 120, 174 BPM: 0 FAIL, 0 WARN).
- 2026-10-26: Renamed viber → **Dendrite** (Hakan's call). PRODUCT_NAME and the CMake target change; the codes Hakd/Vibr, the bundle id `com.hakdiriko.viber` and the APVTS state type `"viber"` stay. Why: JUCE derives the VST3 class ID only from the two codes (`juce_VST3ModuleInfo.h`), so Live reloads old sets, and the state type check would otherwise drop their settings.
- 2026-10-26: New parameter `itch` (version hint 3, default 0.45) takes the slot planned for Motion. Why: one knob for all spontaneous motion. Its regimes (still, breathing, restless, itchy, compulsive) keep the "thresholds, not amounts" principle, and 45% keeps the default sound alive without surprising anyone in a mix.
- 2026-10-26: Breathing = 1/f walk (Voss-McCartney, 8 octaves from about 3 Hz) + a phase oscillator per node with Kuramoto coupling from Ecology (locks past about 60%). Applied to delay time (±0.35%/unit), lowpass (±0.35 oct/unit) and node level (about ±1.5 dB/unit), on top of the old fixed drift. Why: 1/f is the fluctuation spectrum of music and speech (Voss & Clarke 1975); entrainment makes high Ecology breathe as one body; the old drift stays so 0% Itch still doesn't ring metallic.
- 2026-10-26: The itch is an integrate-and-fire engine: 8 band envelopes at 20 frames/s; sameness = 2 s vs 10 s spectrum (and bar-to-bar similarity with a tempo); fill time 40 s (60%) → 3 s (100%), scaled by sameness and by how long the knobs have been idle; noisy threshold; fires on a 4-bar boundary (2 above 85%); relief 8 s → 3 s. Why: deviation that follows repetition, lands on a phrase and is followed by rest sounds intended rather than random (see the brainstorm doc).
- 2026-10-26: Gestures are timed in beats and bars at the host tempo, or as if at 120 BPM without one. Why: musical lengths when there's a grid, sensible lengths when there isn't.
- 2026-10-26: Auto-gain freezes (envelopes and gain) while a scratch plays and for 0.5 s after. Why: otherwise it irons a throw flat within 100 ms and then dips afterwards.
- 2026-10-26: Dub drop ducks the dry, scaled by Mix (no duck at 0%, full from 40%). Why: at Mix 0% there are no echoes to hear in the hole, so it would just be a dropout.
- 2026-10-26: Scars (detune ±0.8 st, echo ±2.5%, tone ±0.12 oct per scratch; caps ±3 st, ±6%, ±0.4 oct) heal with a 3-minute time constant, 15% stays. Saved as a `scars` property in the state. Echo scars only apply when Sync is off. Why: an instance takes on its session's history, a reopened set is the same creature, and Sync stays on the grid.
- 2026-10-26: On play start (with a tempo) the itch restarts its listening and reseeds from the start bar. Why: playing from the same bar gives the same scratches, so an export matches what was heard.
- 2026-10-26: `scratch` is a bool parameter where any flip triggers. Why: a UI button, automation and a MIDI-mapped toggle in Live all work with one parameter. The audit skips it: it only acts on a flip during playback.
- 2026-10-26: `jump` (version hint 3, default off) is the A/B for Sync steps: off = tape bend, on = 25 ms equal-power crossfade between two read heads when a target moves by more than 3%. Why: the brief says ship taste forks as A/B. Lurch always jumps, because a dub engineer's switch cuts.
- 2026-10-26: Phase guard: delay-time wobble (fixed drift and breathing) scales by 1 − 0.8 × transient (the itch's onset rate), smoothed over 0.5 s. Why: dry plus a moving delayed copy is a sweeping comb; Hakan heard it on drum loops. On a synthetic drum loop at defaults, wet bar-to-bar residual went from +1.8 dB (0.2) to −0.3 dB.
- 2026-10-26: The `jump` parameter keeps its ID but is now "Steady": no delay-time wobble at all, and every big time change crossfades (25 ms, equal power), with or without Sync. Why: Hakan asked for a way to bypass the movement; a second switch next to jump would have been one more thing to explain. Measured another −1.9 dB residual at defaults.
- 2026-10-26: New `auto` (version hint 4, default off): moves happen only when it's on; the Scratch button always works. Why: Hakan doesn't want Dendrite breaking a loop unasked.
- 2026-10-26: New `bars` choice (version hint 4): 4/8/16/32/64 bars of repetition before a move, default 16. The counter fills 1/N per bar of exact repetition and a bar of new material empties it. Why: Hakan wanted to control how many bars it listens for; counting in bars makes the meter readable ("same for 9 of 16 bars").
- 2026-10-26: Repeat score = best match of each 50 ms frame (8 bands) against the same moment 1, 2, 4 and 8 bars earlier, read between frames; with a tempo, sameness is only that score (the spectral-steadiness score is the fallback without a tempo). Why: a steady timbre isn't repetition; the old 2 s vs 10 s spectrum comparison counted a changing song with a stable mix as "the same".
- 2026-10-26: New `build` (version hint 4, default on): while the counter fills, breathing deepens up to 1.6× and the network leans 30% toward the chosen move. Why: Hakan's idea that the itch should be felt while the bar fills; shipped as a switch so he can A/B it.
- 2026-10-26: The seven dub gestures are replaced by five moves (open, close, step, lean, tilt) that offset the network's own macros, arrive over a quarter beat, hold 4 bars, return over 2. Ecology never gets pushed past 72% by a move unless the knob is already there. Auto-gain no longer freezes. Why: Hakan disliked every scratch; they were loud, one-off tricks foreign to the network. A move is the network itself changing, at mix level, and it gives the loop back.
- 2026-10-31: **dendrite 1.0** is a new engine on a fresh branch from main (`Source/dsp/Echo`, `Itch`, `Engine`; the 0.3 network is removed). It joins the dotted dub echo of 0.5 (PR #7), the breathing, the mono-safe space Hakan asked for after the 0.5 stab test, and the three heads of the hypnagogic demo (PR #8). Why: Hakan asked for one finished instrument; these are the parts that survived his ears.
- 2026-10-31: Controls: `feed` and `space` (floats, one XY field), `throw` (momentary bool), `frame` (choice, shown as "itch": off, 1, 1¼, 1½, 1¾, 2, 3, 4, 8 bars, default 4) and `bypass`, version hint 8. Why: minimalism, and every control is a gesture. No new switches.
- 2026-10-31: The itch choice is stored under the ID `frame` (the hypnagogic demo's), not `itch`. Why: `itch` was a 0–1 knob in 0.2/0.3, so an old set would have loaded a random frame length (0.45 → off, 0.8 → 1 bar); with `frame`, old sets get the default.
- 2026-10-31: The echo runs in mid/side: the dotted head keeps the Side, the quarter head flips it, and the Mid never receives the Side. Why: the dub ping-pong without hard L/R, and the mono sum is exactly dry + a mono dub echo whatever space does (audit: −139 to −141 dB residual between space 0 and default).
- 2026-10-31: Every pass writes the Mid into the Side again: a pan term (k·sinθ·M) plus a 90° spread term (Niemitalo allpass pair), θ from a slow wander plus the throw's launch and the manipulate head's turn; the quarter head's Side sign goes from −1 (crossing) to +0.92 (keeping) as space rises, and the Side tape uses the same tape lane as the Mid. Why: each repeat steps outward, and at high space the Side grows with every generation instead of cancelling.
- 2026-10-31: Space regimes: inside (only the input's own width, 0.3), around (pan and spread), envelop (five drifting allpasses on the Side loop, faded in from 0.3 to 0.7 of space), beyond (single-sideband shift of the Side, 0.09–0.35 Hz). A trim path keeps the loudness flat (−3.6 dB at the top). Why: four audible regions on one axis, all of them Side-only.
- 2026-10-31: Space paths steepened at the low end (pan 0.08 and spread 0.05 by 0.1; cross −0.5 by 0.1), the Side diffusion faded in instead of switched on at 0.4, and the Side output raised through the middle (1.5 at 0.45, 1.8 at 0.7). Why: the audit flagged space dead zones (0–0.25 on every signal, 0.3–0.6 on the pad), and a width dip at 0.45 where the diffusers switched on and turned coherent build-up into incoherent; now 0 WARN.
- 2026-10-31: Tape pass kept from 0.5 (5450 + 8500 Hz one-poles, 100 Hz high-pass, pre-emphasised tanh at drive 1.16 for dub up to 1.9 at endless, four drifting allpasses at 0.38). Wow and flutter come from smoothed wander, never stepped random. Why: Hakan said the dotted magic survives.
- 2026-10-31: Breathing: duck (0.65 at off → 0.3 at endless, eased while throwing), a 1/f swell of ±3 dB, a brightness tilt that follows it, and up to four bars of fill (more feedback) when the input falls silent. Why: Hakan liked breathing; the duck keeps the echo out of the way of the playing.
- 2026-10-31: The throw opens the send (5 ms), rides the feedback (+0.12/+0.10, capped at 0.9/0.66) and the level (+35%) and launches the image to one side; it falls back over about 2 bars (1-bar time constant), the launch heals in ~10 s. Why: Hakan found the 0.5 throw original but shallow.
- 2026-10-31: A slower throw tail (2-bar time constant) lends the loop at least 0.72/0.5 feedback and brings the return back (1.2·√tail) even at feed off. Why: at feed off the return path was 0, so holding throw did nothing; now off is the dub engineer's closed send.
- 2026-10-31: Wet ceiling at 0.85 × the recent input peak (1 ms attack, 250 ms release), on the Mid and the Side each on its own, on top of the loop ceiling. Why: a throw at dub on chords drove the −0.3 dBFS safety limiter (peak 0.97 from a 0.5 input, 239 samples over 0.9); now 0.73 and none. Separate Mid/Side gains keep the Mid independent of space.
- 2026-10-31: Itch: the listener compares 6 bands per sixteenth with 1, 2 and 4 bars earlier; a frame counts when heard whole, with the heads quiet at its start, and itches when its mean similarity is over 0.72. Intensity grows with the number of bored frames. The heads play the loudest hit of the last bar at gap, 2·gap and 3·gap (gap = frame/4 beats, clamped to 1–2 beats), and the next frame never counts (relief). Seeds come from the frame index, so the same bar itches the same way. Why: from the hypnagogic demo; grabbing a played hit makes the heads a dub gesture rather than a separate effect.
- 2026-10-31: The heads write a share of themselves into the echo tape (scream 0.25, laugh 0.3, manipulate 0.55), and manipulate turns the echo's space with it. Why: the itch should leave its trace in the echo, then let go.
- 2026-10-31: Output: dry untouched, wet crossfaded by bypass over 30 ms, then the instant −0.3 dBFS limiter; NaN guard in the processor; zero latency; tail reported as 12 s. Why: playbook §6; no mix knob because the dry is never touched.
- 2026-10-31: Custom JUCE UI drawn in code (no WebView): an 880×560 design canvas scaled with an AffineTransform, resizable 75–150% at a fixed aspect; Inter Light/Regular/Medium (OFL) embedded; stone, ochre and coral palette; onsets reach the UI through a lock-free FIFO; 60 Hz timer. Why: a finished look with no WebView risk in Live on Windows, and the field shows the echo growing.
- 2026-10-31: The one-page manual is HTML rendered to an A4 PDF with headless Chromium (`docs/manual/render_manual.js`, fails if the page overflows); the PDF is committed and CI puts it next to the plug-in in the Windows and Mac downloads. Why: Hakan asked for one page next to the plug-in.
- 2026-10-31: CI: pushes build Windows and Linux; a manual run (workflow_dispatch) adds macOS with `auval` and pluginval on the AU. Why: Hakan's preference to save effort while he tests on Windows; macOS runs before a release.
- 2026-10-31: Tools: `tools/render` (offline renderer, plain C++ without JUCE, a playing transport) and `tools/snapshot` (renders the window to PNG under xvfb), built with `-DDENDRITE_TOOLS=ON`. Why: pedalboard reports a stopped transport, and a cloud session can't open Live.
- 2026-10-31: The audit skips `itch` and `throw` in its one-at-a-time sweeps (both still play in the random states) and gained a MONO_BREAK check (echo mono sum, space 0 vs default). Why: the itch acts after bars of repetition, longer than a sweep render; throw is momentary; mono safety is now a promise in the UI.
- 2026-11-06: The work on Hakan's 1.0 review is split three ways: sound and itch on PR #9 (branch `claude/project-thread-rtq0cx`), the window and the manual + Corpus copy in their own threads and branches, merged into PR #9 for one build. Why: Hakan offered the split and left the strategy to us; one build and one listening sheet keep his testing simple.
- 2026-11-06: Itch lengths now go down to a quarter bar: off, ¼, ½, ¾, 1, 1¼, 1½, 1¾, 2, 3, 4, 8 (default 4). The choice moved to the ID `frames`. Why: Hakan said the 1-bar minimum isn't short enough. The ID moved because hosts store the choice's index: under `frame`, a 1.0 set saved at 4 bars (index 7) would have opened at 1¾; now old sets open at the default.
- 2026-11-06: After each itch, a frame counts only once the heads have been quiet for at least a bar (for frames shorter than a bar), and the heads' gap is frame/4 beats clamped to ½–2 beats. Why: a quarter-bar frame would otherwise itch almost without pause.
- 2026-11-06: The tape's four diffusers are shorter (1.9–6.6 ms, was 4.7–16.9 ms), their drift is smaller, and the heads read earlier by their total length. Why: an allpass delays what it smears, so every pass landed 41 ms late (0.5 and 1.0): the dotted ⅛ was really 416 ms at 120 BPM, and each generation drifted further off the grid into a wash. Hakan heard "the reverberation working more than the echo". Repeats now land on the grid and keep their edge for a few passes.
- 2026-11-06: Every tape pass thins the low mids: a 150 Hz two-pole high-pass (Q 0.6, was a 100 Hz one-pole) and a −1 dB bell at 280 Hz (Q 0.9). Why: Hakan heard feedback rumble at 220–320 Hz. Measured on a click at dub, the tail held a +16 dB hump at 250–630 Hz; now the 200–330 Hz region stays below 500–1000 Hz on drums, chords and the click.
- 2026-11-06: dub's two heads sum to 0.98 (0.6 + 0.38, was 0.62 + 0.42 = 1.04), and the fill can lift the loop only to a cap that follows feed (0.7 at off, 0.88 at whisper's top, 1.2 at dub, 1.6 at endless). Why: at 1.04 one hit's echo grew for 6 s until the ceiling held it (the "something is feeding too much"); and whisper's fill lifted it to 0.99, so whisper droned in the gaps. Now one hit at dub falls ~10 dB over 6 s, and whisper falls 30 dB in 4 s; drown and endless still regenerate.
- 2026-11-06: Five heads (scream, laugh, manipulate, swarm, ghost); each itch draws three, in a random order, never the same three twice running. Why: Hakan asked for more itches; three per itch keeps an itch as long as before, and the draw keeps it organic.
- 2026-11-06: Every head is placed by `Binaural`: Woodworth interaural time difference, Brown–Duda head shadow per ear (one-pole/one-zero, +6 dB of highs on the near ear, −20 dB on the far), a pinna dulling from behind and a near-field level difference. The scream now circles the head 1–2 times as it climbs (it sat at one fixed angle in 1.0). Why: Hakan said the scream doesn't happen around his head. The heads' mono sum is now the event itself, no longer a mostly-Side sound.
- 2026-11-06: New head swarm: twelve oscillators at eighth-note rates ±12–20%, Kuramoto-coupled (coupling rising over 60% of the head) and drawn to the beat grid; each fires a 30–70 ms grain of the attack from its own azimuth, and the cloud closes to the front as it locks. Why: chaos to order, from Hakan's research list (Kuramoto); organic and randomised.
- 2026-11-06: New head ghost: the accent's air (two 1.7 kHz high-passes) smeared by a 160-tap velvet-noise sequence (220 ms, 70 ms decay) and played slightly slower, close to one ear, passing behind the head to the other. Why: velvet noise from Hakan's research list; a whisper at the ear is the hypnagogic presence.
- 2026-11-06: Heads levelled by K-weighted momentary loudness on drums, a dub loop and chords (gains 0.85, 2.7, 1.4, 2.6, 5.5); all five within ~2 dB on the loop, and each head soft-clipped at 0.85 × the peak of the accent it plays. Why: laugh measured ~10 dB under scream (Hakan: one itch is really weak); the clip keeps the levelled heads from pushing the output limiter.
- 2026-11-06: The first quarter of space widens a little sooner (pan 0.13 at 0.1 and 0.21 at 0.3, spread 0.1 and 0.2) and inside is more centred (Side out 0.35 at 0, 1.05 at 0.25). Why: with the low mids thinned on every pass, the audit found a dead zone on the pad over space 0–0.25 (the pad's echo is mostly low end, so its Side grew less). The audit's replica distance went from 1.15 to 1.49 dB.
- 2026-11-06: Window 1.1 is true black with no panels or frames; the field covers the whole window and its edges sink into black. Why: Hakan wanted it to feel like the inside of a brain, and asked for true black.
- 2026-11-06: The background is living tissue (28 strands that grow in, sway on a few slow travelling waves, retract after 30–80 s and are replaced at random), with impulses running toward their roots, more of them when the echo is loud, while throwing and (coral) while itching; the light reveals the tissue near it. Why: Hakan said the strands were "constant" and asked for details that impress in a sprezzatura way.
- 2026-11-06: Growth from hits is a soft body (Verlet point masses on springs). Young branches hang free on the light and trail when you drag; older ones root, stretch thinner, peel past a per-tree limit and stay; tethered roots let go after being carried 55–205 px. Branch timing still follows the echo's repeats (dotted keeps its side, quarter crosses), but every tree draws its own temper (curl, fork rate, reach, bend, jolts, peel and stretch limits) and the shape is chance. Why: Hakan: "they keep dendriting where they've started... no dragging feeling" and "too predictable".
- 2026-11-06: Text cut to the name, "itch" with only the chosen length (all 12 show on hover), head names only while a head plays, and two regime words under the light while you touch it. Gone: subtitle, tempo/mono chips, edge regime names, footer hints, version, panel titles. Why: Hakan: "too much unnecessary text".
- 2026-11-06: Heads each leave their own trace: scream a coral tendril that circles as it climbs, laugh short twigs alternating sides, manipulate a spiral, swarm grains that close in on the light as they lock, ghost pale strands that pass from one side over to the other. Why: five heads now play (three per itch).
- 2026-11-06: The window draws with native lines (curves cut into a few straight pieces) and gradient edges instead of a full-window overlay image. Why: about 5 ms per frame at 100% and 8 ms at 150% in software rendering, safe for 60 fps.
